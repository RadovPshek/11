# Лабораторная 11-12: Знакомство с инструментальными средствами анализа данных

В рамках данной работы студенты знакомтся с возможностями, которые предоставляются средами 
анализа данных Orange (https://orangedatamining.com/) и Deductor (https://basegroup.ru/deductor/description).

Каждое из заданий предполагает выполнение последовательности манипуляций над набором данных
и оформление текстового отчета.

Сами задания с описанием требований к отчету, а также сопутствующие наборы данных, находятся в каталоге docs.

Готовые отчеты в формате PDF (НЕ docx, odt и т.п!) необходимо разместить в каталоге reports.
